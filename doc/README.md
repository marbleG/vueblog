# 项目工程文档

本目录用于维护 `vueblog` 项目的运行、架构、流程和规范，**不会被 VuePress 渲染**。

## 目录说明

| 目录 | 用途 |
|------|------|
| `architecture/` | 系统架构、仓库结构、数据流 |
| `runbooks/` | 操作手册、故障处理、发布流程 |
| `standards/` | 写作规范、Obsidian Vault 使用约定 |
| `operations/` | 变更记录、运维日志 |
