# 代码质量与重构

本栏目收录「代码质量与重构」相关的文章与笔记。

## 原则

- **童子军规则**：让代码比你来时更干净（leave it better than you found it）。
- **命名即文档**：好名字省掉一半注释；注释只解释"为什么"，不重复"是什么"。
- **小步提交、频繁集成**：每次改动小而完整，降低回退与合并成本。
- **三次才抽象**：重复出现第三次再抽公共逻辑，避免过早泛化。
- **重构不改变行为**：有测试护体才敢大改；没测试先补测试。
- **单一职责**：一个函数/模块只做一件事，并把它做好。
