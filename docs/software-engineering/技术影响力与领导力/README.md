# 技术影响力 / 领导力

本栏目收录「技术影响力 / 领导力」相关的文章与笔记。

## 原则

- **教人胜于写代码**：放大团队产出比个人英雄更有杠杆。
- **Owner 意识**：为结果负责而非为任务负责，主动推动闭环。
- **用影响力而非职权**：靠专业与数据说服，而非职位压人。
- **做难而正确的事**：技术债、架构风险要有人敢牵头处理。
- **沉淀与分享**：把踩过的坑、最佳实践写成可复用知识资产。
- **成就他人**：帮助同事成长、把机会让给新人，是领导力的体现。
