# 编程与语言功底

本栏目收录「编程与语言功底」相关的文章与笔记。

## 原则

- **理解优先于记忆**：吃透语言机制（内存模型、求值顺序、并发语义、类型系统）比背语法更值钱。
- **代码是写给人看的**：编译器只是顺便执行；可读性优先于"聪明"。
- **把错误信息当朋友**：先读懂报错与栈帧，再动手，拒绝盲改试错。
- **最小惊讶原则**：行为与读者预期一致，避免隐式副作用与全局可变状态。
- **边界显式化**：入参校验、空值、异常在边界就处理，别在深层悄悄吞掉。
- **吃透工具链**：调试器、profiler、linter 用熟，而不是只会 `print`。
