# 协作与沟通

本栏目收录「协作与沟通」相关的文章与笔记。

## 原则

- **写清楚比说清楚更持久**：文档、PR 描述、设计稿能跨时区跨时间传递。
- **异步优先**：尊重他人心流，重要的事留痕，不靠口头同步。
- **先对齐目标再对齐方案**：确认"做什么、为什么"，再讨论"怎么做"。
- **评审是双向学习**：代码评审既保质量也传播知识，态度要善意且具体。
- **术语一致**：团队对核心概念用词统一，减少无谓误解。
- **及时暴露风险**：能预估的问题早说，比延期后爆雷好。
