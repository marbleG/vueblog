# 调试与问题定位

本栏目收录「调试与问题定位」相关的文章与笔记。

## 原则

- **先复现，再诊断**：不能稳定复现的问题不要急着改。
- **看证据，不猜**：用日志、断点、profiler 拿数据，而非凭直觉改。
- **二分法收窄**：版本回退、最小化复现、屏蔽变量，快速逼近根因。
- **一次只改一个变量**：并行改多个会让你分不清谁真正有效。
- **治根因而非表象**：修的是"为什么出错"，不是让报错消失。
- **能复现就解决了一半**：写出稳定复现脚本，问题已近在咫尺。
