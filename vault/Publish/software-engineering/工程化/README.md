# 工程化 / CI-CD / DevOps

本栏目收录「工程化 / CI-CD / DevOps」相关的文章与笔记。

## 原则

- **自动化一切可重复的**：构建、测试、部署、环境一律交给流水线。
- **快速反馈循环**：提交后几分钟内有红/绿，而不是上线才暴露问题。
- **环境一致性**：开发=测试=生产，靠 IaC 与容器消灭"我机器上能跑"。
- **小批量、高频发布**：大版本风险高；小步快跑更易回滚。
- **一切皆代码**：流水线、配置、基础设施纳入版本管理，可审计可回退。
- **可观测的发布**：灰度、监控、一键回滚是发布的标准动作。
