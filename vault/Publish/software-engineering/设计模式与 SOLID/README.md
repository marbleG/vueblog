# 设计模式与 SOLID

本栏目收录「设计模式与 SOLID」相关的文章与笔记。

## 原则

- **SOLID 是约束不是教条**：原则是权衡工具，不要求全套套用。
- **组合优于继承**：用组合表达"有什么"，继承表达"是什么"。
- **面向接口编程**：依赖抽象而非具体实现，便于替换与测试。
- **对扩展开放、对修改封闭（OCP）**：新增能力尽量不改动旧代码。
- **接口隔离（ISP）**：客户端不应被迫依赖用不到的接口。
- **里氏替换（LSP）**：子类必须能替换父类而不破坏既有预期。
- **模式服务于变化点**：只在变化确实发生处引入模式，别"为模式而模式"。
