# 测试与质量保障

本栏目收录「测试与质量保障」相关的文章与笔记。

## 原则

- **测试金字塔**：多单元测试、少端到端，性价比最高。
- **测试必须能失败**：永远绿不了的测试只是装饰。
- **覆盖关键路径与边界**：先保核心逻辑与异常分支，而非追求 100% 行覆盖。
- **测试即文档**：好的用例是可执行、永不过期的规格说明。
- **反馈要快**：测试慢就会被跳过；CI 里跑测试是底线。
- **测行为不测实现**：断言对外行为，重构内部时才不痛苦。
