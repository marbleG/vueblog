# 需求与产品思维

本栏目收录「需求与产品思维」相关的文章与笔记。

## 原则

- **先问"为什么"**：动手前弄清问题是什么、为谁解决、价值在哪。
- **用户价值优先**：技术服务于业务结果，不为技术而技术。
- **MVP 思维**：用最小成本验证假设，再投入扩展。
- **区分需求与方案**：用户常给"方案"，要挖掘背后的真实"需求"。
- **定义可量化的成功标准**：上线前说清怎么算"做好了"。
- **拥抱变化但管控范围**：需求会变，用优先级与边界管理变更。
