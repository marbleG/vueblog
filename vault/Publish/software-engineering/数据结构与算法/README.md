# 数据结构与算法

本栏目收录「数据结构与算法」相关的文章与笔记。

## 原则

- **选对结构胜过写对算法**：时间复杂度的差距常由数据结构的选择主导。
- **先估复杂度再动手**：动手前想清 O(1)/O(log n)/O(n)/O(n²) 的真实代价。
- **权衡是常态**：空间换时间、时间换空间，要能说清"为什么选这个"。
- **标准库优先**：手写轮子前先确认没有现成、可靠、被广泛检验的实现。
- **正确性先于优化**：先写对、再测对、最后才谈快；过早优化是万恶之源。
- **盯紧边界与不变式**：空集合、单元素、溢出、重复元素、相等性这些坑先想明白。
