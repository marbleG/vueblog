# 能力地图（Capability Map）

> 软件工程能力的结构化拆解 + 自评基线。**这是「自分析」的核心**：
> 先快照当前水平，再定目标，后续每次复盘回来更新，就能看到成长曲线。
>
> 评分标准（1-5）：
> 1 = 听说过 / 2 = 了解概念 / 3 = 能在指导下完成 / 4 = 能独立且质量稳定 / 5 = 能教会别人 / 定规范

## 使用方式

- **首次填写**：把「当前」列填成真实基线，「目标」列填 3-6 个月想达到的档位。
- **每次复盘更新**：只改有变化的维度，并在 [[软件工程/复盘]] 记一句为什么变。
- **抓重点**：优先练「优先级高且 当前<目标」的维度，对应到 [[软件工程/刻意练习]]。

## 能力维度说明（可展开）

- **编程与语言功底**：不止会写，还要懂惯用法、异常边界、性能特征。
- **代码质量与重构**：能识别坏味道并安全重构，是日常最高频的能力。
- **系统设计 / 架构**：在约束下做权衡，而非套用「最佳实践」。
- **测试与质量保障**：把质量内建进流程，而非靠人工兜底。
- **调试与问题定位**：把「能跑」变成「知道为什么能跑 / 为什么挂」。
