# 软件工程能力提升

> 一个**自我驱动的软件工程能力成长模块**：把「学 → 练 → 复盘 → 评估」的闭环落库，
> 让能力提升的过程可追踪、学到的知识可检索。
> 本模块是**私人成长工作区**（能力地图/练习/复盘/模板留在这里）；写成的**知识文章默认分享**——直接放到 `Publish/software-engineering/`（按二级子栏目归类，如 API 设计归入 `系统设计`）。

## 怎么用这个模块（成长闭环）

```
    ┌──────────┐     ┌──────────┐     ┌──────────┐     ┌──────────┐
    │  学 习   │ ──▶ │  刻 意   │ ──▶ │  复 盘   │ ──▶ │  评 估   │
    │ 学习笔记 │     │  练 习   │     │   复盘   │     │ 能力地图 │
    └──────────┘     └──────────┘     └──────────┘     └──────────┘
          ▲                                                  │
          └──────────────── 新知识 / 新目标 ◀────────────────┘
```

1. **学**：读到/实践到一个知识点 → 用 [[软件工程/学习笔记模板]] 落到 [[软件工程/学习笔记]]。
2. **练**：针对薄弱环节做**刻意练习**，记到 [[软件工程/刻意练习]]。
3. **复盘**：定期（周/双周）写 [[软件工程/复盘]]，总结进展与卡点。
4. **评估**：在 [[软件工程/能力地图]] 更新自评，看哪些维度在涨、哪些停滞。
