## 设计模式

- 单例推荐用**枚举**实现：天然防反射、防序列化，线程安全 → [[Publish/design/singleton|singleton]]
- 工厂方法把"实例化"延迟到子类；抽象工厂生产**产品族** → [[Publish/design/factory-method|factory-method]] / [[Publish/design/abstract-factory|abstract-factory]]
- 建造者适合**多参数、可选配置**对象的构造 → [[Publish/design/builder|builder]]
- 适配器解决**接口不兼容**；装饰器**动态叠加职责**；代理控制**访问** → [[Publish/design/adapter|adapter]] / [[Publish/design/decorator|decorator]] / [[Publish/design/proxy|proxy]]
- 观察者实现**一对多**通知；策略封装**可互换算法** → [[Publish/design/observer|observer]] / [[Publish/design/strategy|strategy]]

## Java / JVM
